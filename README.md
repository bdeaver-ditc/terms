# terms.deaverit.com

Published versions of the Deaver IT Consulting Hourly Service Terms, served by GitHub Pages at https://terms.deaverit.com.

- Each version is published in its own folder (for example, `hourly-v1-3/`) and is not edited after publication.
- A new version is published as a new folder, and the version list in `index.html` is updated.
- The hourly rate does not appear in these files. It is stated in each Work Authorization.
- `assets/logo.png` is the navy-background horizontal lockup. The header band color (`#112946`) matches the logo's baked-in background.
